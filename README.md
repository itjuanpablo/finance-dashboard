# 💰 Nome do Projeto

> Uma aplicação web para organização de finanças pessoais, com foco em clareza, controle e simplicidade.

---

## 📌 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de ajudar no controle financeiro pessoal, permitindo registrar receitas, despesas e acompanhar o fluxo de dinheiro de forma prática.

A ideia é transformar a forma como o usuário enxerga e administra suas finanças.

---

## 🚀 Funcionalidades

- ✅ Cadastro de receitas  
- ✅ Cadastro de despesas  
- ✅ Visualização do saldo
